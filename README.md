# EJOos

EJOos is a web-based desktop environment designed to mimic a retro operating system layout. It runs directly inside your browser and includes a built-in suite of applications, utility tools, and arcade games.

## System Functions & Features

* **Welcome Screen:** Displays a quick overview of available system functions and applications upon startup.
* **Terminal:** A command-line interface that supports basic operations, system info commands, file listing, and a hacker text stream mode.
* **Notes Editor:** A text utility allowing users to create, view, save, and delete text documents.
* **Photos:** A gallery viewer that lets you browse images and set them as your desktop wallpaper.
* **File System:** A virtual directory explorer that organizes your saved documents and images into folders.
* **Calculator:** A standard arithmetic calculator for quick calculations.
* **Pixel Paint:** A drawing canvas tool with color selection options and a clear function.
* **Retro Snake:** A grid-based arcade snake game with score tracking.
* **Minesweeper:** A classic puzzle game featuring a timer, mine counter, and interactive grid cells.
* **Desktop Sudoku Gadget:** A live logic puzzle widget built right onto the main desktop page with difficulty selection and a number keypad.
* **Retro Camera:** A tool that connects to your webcam to snap photos and save them directly to your photo gallery.
* **8-Bit Audio Player:** A chiptune music player with built-in synthesized tracks and playback controls.
* **Retro Web Browser:** A simulated web client featuring historical web pages, an address navigation bar, search functionality, and a public guestbook.
* **Chatbot:** An interactive assistant that responds to queries and saves conversation history.
* **System Settings:** Allows users to switch between retro color themes, upload custom background wallpapers, manage user profiles, and perform a system reset.
* **Task Manager:** Monitors live CPU and RAM usage metrics while allowing users to close active running applications.
