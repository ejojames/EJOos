# EJOos

EJOos is a retro-red themed web operating system built using HTML, CSS, and Vanilla JavaScript. It provides a desktop window management system alongside built-in applications including a terminal, a note editor, a photo viewer, and a file browser.

## Features

- Multi-window desktop environment
- Draggable application windows
- File Explorer with folder navigation
- Notes application with active document editing
- Interactive terminal with built-in commands
- Photo viewer with gallery selection
